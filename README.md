# Générateur de planning

Ce projet contient un script React (`.jsx`) généré avec Claude permettant de créer et d'organiser facilement un planning.

## Comment l'utiliser
1. Téléchargez le fichier `generateur-planning.jsx`.
2. Intégrez-le dans un projet React existant ou exécutez-le via un éditeur en ligne comme CodeSandbox ou StackBlitz.
